聚会时间：2027年2月8日，星期一，09:00—21:00。
聚会地点：长乐农业中学。
在线地址：https://anxbin.github.io/class-reunion-30/
GitHub 仓库：https://github.com/ANXBIN/class-reunion-30

## 预览与发布

双击根目录 `index.html`，用浏览器直接打开。这个文件已内嵌全部24张照片、样式和脚本，可以独立保存或上传到 GitHub Pages，不依赖其他项目文件。
普通网址先展示姓名输入页；输入姓名后进入专属邀请函。也可以在网址末尾加 `?name=同学姓名`，直接打开对应称呼版本。
姓名和“收下邀请”的留念仅存在当前设备，不会提交报名。

## 文件结构

- `index.html`：当前完整邀请函，发布使用的文件。
- `src/`：页面模板、样式、交互脚本和活动/相册数据。
- `assets/photos/`：打包所用的24张照片，保持原始照片内容与比例。
- `资料/原始照片/`：用户提供的原图。
- `资料/活动安排参考.jpg`：活动流程参考图。
- `资料/照片来源对照.json`：照片编号与原文件名对照。
- `scripts/build.py`：单文件生成脚本，使用 Python 标准库，无需安装依赖。
- `预览/`：手机排版检查截图。
- `发布包/`：供迁移托管或备份的压缩包。
- `历史版本/`：之前的示例、Sites项目、GitHub首版项目和旧发布包。
- `工作文件/`：照片总览及临时检查文件。

## 更新内容

活动和照片说明修改 `src/content.json`；正文修改 `src/index.template.html`；样式修改 `src/styles.css` 或 `src/overrides.css`；交互修改 `src/app.js`。
修改后运行：

```sh
python3 scripts/build.py
```

重新生成的 `index.html` 上传至 GitHub 仓库的 `main` 分支根目录，会触发 Pages 自动发布。
照片不裁切主体；相册支持分类跳转、手动和自动翻页、触摸滑动、点击放大。
联系方式、费用及交通集合细节尚待筹备组补充。
